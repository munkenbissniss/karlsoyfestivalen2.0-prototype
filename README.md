# Karlsøyfestivalen – klikkbar prototype (utkast 2)

To utgaver i samme mappe:

- `index.html` – **fase 1**: det som skal virke til festivalen 27. juli – 1. august 2027.
- `fase2.html` – **fase 2 og valgfrie tillegg**, merket «Fase 2»: Discord-kanaler og møterom i grensesnittet, oppgaver med roller og status, kvitteringer og utlegg, medlemskap i foreninga, husutleie, tidligere år og verktøykasse.

Stripa øverst lar deg vise siden **før**, **under** eller **etter** festivalen, og bytte mellom fasene.

## Publisere på Codeberg Pages
Last opp hele mappa til et repo (for eksempel `pages`) på Codeberg. Ingen byggesteg. `.nojekyll` ligger med.

## Data
- `js/data.js` – program 2026, steder, kategorier, bidragsytere, grupper, frister, FAQ (fra kildene).
- `js/data-extra.js` – håndbokkapitler, blogg, kunngjøringer, Tavla-kort, driftsmeldinger og fase 2-data (mye er eksempler).
- `js/i18n.js` – grensesnitt på norsk, engelsk, fransk og nederlandsk.

Fonten er Manrope (som dagens nettside), lagt med i `assets/fonts` under SIL Open Font License. Den lastes fra egen server, ikke fra Google.
Bilder: håndboka v9.1 og dagens nettside. Portretter av bidragsytere er plassholdere.
